# 学习成果检查

分享作品时，请让另一位使用者按你的说明操作，并回答以下问题。

| 观察项 | 可展示的证据 |
|---|---|
| 问题清楚 | 用一句话说明希望改善哪一种体验，而不是只列工具名 |
| 改动明确 | 指出一个规则、参数或几何区域，解释改动理由 |
| 验证可重复 | 记录起始状态、操作步骤、预期与实际结果；修改前后采用相同条件 |
| 判断有依据 | 区分已经观察到的结果、照片能够支持的细节与尚未证实的推断 |
| 能够交接 | 同伴能按 README 运行、知道按什么键，并了解剩余问题 |
| 公开范围明确 | 保留来源和许可证，不提交真实 Key、账号信息或未经授权的模型与照片 |

游戏作品可以提交一次任务的操作记录和前后对比；重建作品可以提交同一相机位置的局部对照，并圈出推断补建的区域。视觉完整不等于测量准确，不要求把未验证的部分说成已经正确。
