## 实践

先熟悉移动、换层、资源与信标任务。读取 `public/rules.mjs`，只调整一个配方或消耗参数；用同一路线比较前后体验。联机和 AI 可在单人任务稳定后选做。改变建筑布局时，同时检查导航、楼梯与任务位置。

## 一起讨论

更容易完成是否一定更有趣？同伴是否能解释规则？哪些状态由客户端上报，哪些由服务端检查？
