# 从照片到空间

[返回课程](../../README.md) · [完整源码与操作说明](../../code/office-reconstruction/README.md)

建议学习活动时间：180 分钟，可拆分；安装、下载和计算等待另计。

## 实践

按操作手册检查工具路径，再获取公开 office1a 数据。先理解标定照片与初始网格，选择一个局部修复阶段。用相同相机比较修复前后，并明确指出有照片证据和依靠推断的区域。完整管线可作为后续扩展。

## 一起讨论

孔洞为什么会出现？补上一面墙的证据是什么？同一视角的对照能证明什么，又不能证明什么？
