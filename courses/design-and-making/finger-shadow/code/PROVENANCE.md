# 来源与适用范围

研发 · AHALab X ZimaBlueAI

课程由 AHALab 编写，结合手指操偶、英语原创短剧与部编版习作要求。教案是可调整的课堂安排，未声称由具名特级教师审定或已完成全班试教。

- [课程文章](https://mp.weixin.qq.com/s/sBJoPbetgkh9iIuMOeFJxA) 提供创作缘起与体验；本文不复制课堂原照片。
- [中国非遗网](https://www.ihchina.cn/Article/Index/detail?id=24898) 提供传统皮影形制与雕镂参考，数字插画不作为古代实物证据。
- [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js) 为21点手部估计。固定 Web 组件0.10.32与模型资产摘要见 vendor/manifest.json。框架许可保存在 vendor/MEDIAPIPE-LICENSE.txt；模型保持其上游声明。
- [OC-SORT](https://github.com/noahcao/OC_SORT/tree/8462e7e729a93ccd3bd995c0a79a890336cb3a0b) 为可选本机运动跟踪。配置脚本按固定版本下载所需三模块并检查摘要，保留原作者 MIT 声明。
- [SenseVoice](https://github.com/QwenAudio/SenseVoice) 提供语音识别。[Wav2Vec2音素模型](https://huggingface.co/vitouphy/wav2vec2-xls-r-300m-timit-phoneme) 单独估计音素。固定版本和文件摘要见 speech/models.json。
- 英语台词为原创课堂脚本，未复制歌曲歌词或词典释义。6份整剧与58份逐句示范由 Microsoft Zira Desktop 合成，声音来源保留在 assets/english/manifest.json。
- 四段配乐为课程编曲，使用 YuE2 制作，运行所需声音文件与摘要见 assets/music/manifest.json；不分发 YuE2 模型权重。
- 七位传统题材影人、幕布、道具与宣传插画为数字改编，逐项署名和摘要见 assets/manifest.json。第三方现代动画角色素材未包含在本课程包中。

原创教学文案与所持插画、编曲权利按 CC BY 4.0 提供；原创代码按 MIT。AHALab Logo 仅用于标识研发出处。第三方软件、模型、声音及独立肖像权利分别处理。

10槽位演示不代表真实10只手的准确率测试。参考发音分未用儿童语音校准；macOS 路径已适配，仍需实机验证。画板的数字镂空不检查实体纸桥连通性，剪纸前应试剪并修改。
