分龄教案与课件

选好课次，可以看详案、投屏带课，也可以打印学生记录单。

教师备课稿，待试教。请按学生已有经验和课堂观察调整进度。

学生年龄

8 次课，每次 90 分钟。从纸面规则进入参数操作；用自己的记录解释一次修改。

7至9 岁四课为独立短课；10至12 岁与 13至15 岁各八课。可按阅读、操作和已有经验选用，年龄只作备课参考。

7至9 岁 · J01 · 60 分钟

我的影人会招手

不说话，你能让同伴看出它在招手吗？

这节课要练什么

  • 给影人加两处认得出的特征。
  • 接好一只会动的手臂，演给同伴猜。

课后留下会动的纸偶、同伴猜动作的原话和一处修改。

课前准备

每组卡纸、描图纸、安全剪刀、纸铆钉、白纸幕和低温 LED 灯；打开角色工坊。准备断开的镂空纸样与留有纸桥的纸样，并备有来源的传统皮影实物或馆藏图；项目生成角色用作改编对照。

先看学生会不会

请学生指认头和手臂，再试着叠放两张纸。需要帮助时直接提供预制关节片。

按实际表现选帮助，不把年龄当作能力分数。

这节课怎么上

引导语供备课使用，可换成自己的说法。每 15至20 分钟安排放下手或轮换岗位；这段时间计入各环节。

0至8分钟

猜一猜轮廓

看看这个影子。你发现了什么？用手指一指。

留意学生可以指认耳朵、帽子或道具，不要求完整句。

接着这样问或做遮住这处特征再看，接住学生的不同猜法。

8至15分钟

选一件要做的事

它想送什么给谁？画下来，或者说给我听。

留意学生能说一件小事，如送桃子、送灯。

接着这样问或做给两张道具卡供选择，不替学生取名字。

15至40分钟

接一只手臂

先把这两片叠起来。请我帮你穿好，再轻轻转一转。

留意学生成人处理关节连接，学生决定位置和样子。

接着这样问或做先完成一只手臂再加其他部位；每十五分钟左右放下材料活动一下。

40至55分钟

你演我猜

先不说答案。动一动，让同伴猜。

留意学生观众能说出看到的动作。

接着这样问或做作者选一个地方改，再演一次。

55至60分钟

留下两张图

指一指，你刚才改了哪里？

留意学生允许圈画和口述。

接着这样问或做老师原样记一句学生的话。

黑板上留这些

角色想做什么 → 哪个部位要动 → 关节放哪里 → 同伴看懂了吗

遇到这些情况

  • 把花纹刻得越密当作越好

    请他拿起纸样，看看哪一处先断。圈出需要保留的连接，再减少一处镂空。

  • 把数字角色当作可以直接剪成的纸样

    让学生打印一片并实际剪开；数字画板不会检查纸桥是否连通。

需要帮助时

提供预剪身体与大关节片，学生选特征和道具；不要求完成全部七片。

已经做完，可以再试

让同一个影人演招手和举灯，请同伴分辨。

下课前问一句

举起你的影人，演一个动作；指着改过的地方说一说。

请每位学生留下一句回答、一次指认或一张小图。下一课先看没弄清的地方。

7至9 岁 · J02 · 60 分钟

小点跟着手指走

把一根手指藏起来，画面上的小点会怎样？

这节课要练什么

  • 找到画面里跟着指尖走的小点。
  • 试一次遮挡，说出前后看到的变化。

课后留下遮挡前后示意图、三次尝试的口述或圈画记录。

课前准备

固定摄像头、桌面柔光灯、遮挡卡、手部轮廓纸。教师先确认实验台能显示骨架；准备手绘骨架作为设备故障时的替代材料。

先看学生会不会

先确认学生能在画面里找到自己的手，再请他慢慢移动一根手指。

按实际表现选帮助，不把年龄当作能力分数。

这节课怎么上

引导语供备课使用，可换成自己的说法。每 15至20 分钟安排放下手或轮换岗位；这段时间计入各环节。

0至10分钟

找我的手

把手放进画面。找到了吗？慢慢动一动。

留意学生知道摄像头画面对应自己的手。

接着这样问或做老师固定设备；也可先用鼠标看角色。

10至20分钟

跟着一个点看

只看食指尖的小点。手指向上，它去哪儿了？

留意学生能指认一个对应关系。

接着这样问或做放慢动作，避免同时追所有点。

20至35分钟

先猜再遮

先猜一猜。现在用卡纸挡住这根手指，再看看。

留意学生学生区分自己预测与实际看到的变化。

接着这样问或做一人摆手，一人观察，之后互换。

35至50分钟

挪开卡纸再试

把卡纸拿开。小点回来了吗？再试两次。

留意学生至少做三次独立尝试，结果不同时也保留。

接着这样问或做结果不清楚就说“我还没看清”，再放慢一次。

50至60分钟

画两幅小图

画没挡住和挡住的时候。哪儿不一样？

留意学生允许点线示意和教师代记。

接着这样问或做不要求低龄学生记住模型名称。

黑板上留这些

看到手的画面 → 估计关节点 → 按规则控制影人
记录：条件 / 我看到了什么 / 还不能确定什么

遇到这些情况

  • 骨架有点就一定准确

    请学生指出一个点在真实手上的对应位置；保留明显偏离的例子。

  • 一出错就换模型

    先确认画面是否清晰、手是否完整入镜，再判断错误发生在哪一段。

需要帮助时

教师操作遮挡卡，学生只观察一个指尖；可以用指认代替书写。

已经做完，可以再试

换同伴的手重复，看看是不是也有相同变化。

7至9 岁 · J03 · 60 分钟

中指带着头点一点

哪根手指能让影人点头？

这节课要练什么

  • 找到控制头和一条腿的手指。
  • 让角色靠近道具，试一次拿起和放下。

课后留下手指连线卡、点头和拿放道具的一次演示。

课前准备

五指连线卡、实验台与一件可搬道具。教师确认组合手势和个人分类器起初均关闭，先做独立手指观察。

先看学生会不会

请学生指一下中指和拇指；允许同伴帮助，不要求记住全部手指名称。

按实际表现选帮助，不把年龄当作能力分数。

这节课怎么上

引导语供备课使用，可换成自己的说法。每 15至20 分钟安排放下手或轮换岗位；这段时间计入各环节。

0至10分钟

先用滑块看

拖动中间这根滑块。看，影人哪里动了？

留意学生先看到明确对应，再使用摄像头。

接着这样问或做把头与中指画在同一张连线卡上。

10至20分钟

中指动一动

掌心先停住。中指弯一点，再伸开。

留意学生不要求其余手指完全不动。

接着这样问或做感觉累就换滑块或请同伴接力。

20至35分钟

拇指带着腿

拇指向外打开，再收回来。看看腿动了多少。

留意学生观察弯曲与外摆，老师协助调灵敏度。

接着这样问或做只在 1 倍和 2 倍中试选，抖动大就调低。

35至50分钟

给影人一盏灯

先靠近灯。捏起来。再张开手，放下。

留意学生每说一个动作留操作时间；老师先完成校准。

接着这样问或做拿不到时改用“拿起 / 使用”与“放下”按钮。

50至60分钟

交换操偶师

请你教同伴做刚才的一个动作。一次只说一步。

留意学生同伴能照着做，学生能指认控制关系。

接着这样问或做收好连线卡，手放下休息。

黑板上留这些

拇指 → 左腿；食指 → 左臂；中指 → 头；无名指 → 右臂；小指 → 右腿
普通移动 / 有意触发：分开计数

遇到这些情况

  • 无名指和小指不能完全独立就是做错了

    承认手指会联动，允许较小幅度或滑块操作；评价规则和观察，不评价手的灵活程度。

  • 放大拇指就能改善捏合识别

    拇指灵敏度只放大操偶动作。捏合与组合手势仍使用未放大的输入。

需要帮助时

本课只检查头和一条腿；其他手指可以一起动。按钮、滑块与摄像头任选。

已经做完，可以再试

补齐五指连线卡，再用一句话教同伴一个动作。

下课前问一句

指出控制头的手指，再选一种方法把道具放下。

请每位学生留下一句回答、一次指认或一张小图。下一课先看没弄清的地方。

教师操作提醒

拇指摄像头灵敏度可调 1至3 倍，默认 2 倍。组合手势需要主动开启，先张掌；V 手势跳跃、竖拇指转身，保持约半秒。翻手翻面默认开启，初次稳定入镜的手面记为正面，侧手时保持朝向。每次动作后重新张掌。道具拿放与接月在不同练习中进行。

7至9 岁 · J04 · 60 分钟

灯送到，戏开场

你们能合演一段送灯的小故事吗？

这节课要练什么

  • 选一个背景和两件道具，演出一件小事。
  • 听同伴说看到了什么，再改一个动作。

课后留下三格故事图、一段小戏和学生对自己决定的说明。

课前准备

两分钟剧本卡、背景与道具清单、个人发言卡。选英语戏剧时另备本龄段台词卡，教师先领读并圈定难词。每组保存设计 JSON 与参数记录；教师先排好轮流上场顺序。

先看学生会不会

请学生用自己的影人演一个动作，老师据此分配操偶与讲述岗位。

按实际表现选帮助，不把年龄当作能力分数。

这节课怎么上

引导语供备课使用，可换成自己的说法。每 15至20 分钟安排放下手或轮换岗位；这段时间计入各环节。

0至10分钟

选故事发生的地方

这盏灯要送给谁？故事在哪里发生？选一幅背景。

留意学生能选择一件事情，不急着编长故事。

接着这样问或做也可以改成送桃子或找花球。

10至20分钟

摆两件道具

先摆桌子，再把灯放到你想要的地方。

留意学生老师协助鼠标操作，学生决定位置。

接着这样问或做石桥用作背景参照，不安排尚未实现的走桥碰撞。

20至40分钟

两人轮流演

你操偶，他讲一句话。再换过来。

留意学生每人都有一次操作或讲述机会。

接着这样问或做一个浏览器只用一个原创角色，另一位可选已有角色。

40至55分钟

请观众看

观众先说：我看到____。作者听完，再选一个动作重新演。

留意学生反馈落在动作和故事上。

接着这样问或做设备不配合就拿实体影人继续；音乐可省略。

55至60分钟

说一句自己的发现

今天哪一步是你决定的？指给大家看。

留意学生允许短句、指认与代记。

接着这样问或做留下作品和学生原话，不按花纹多少排名。

黑板上留这些

角色想做什么 → 遇到什么事 → 怎样解决
我改了什么 / 观察到了什么 / 下一步想试什么

遇到这些情况

  • 表演最流畅的小组就学得最好

    同时看个人解释、测试记录与修改理由；设备故障不直接扣学习分。

  • 多个原创角色能在同一浏览器同时保存使用

    当前只保留一个原创角色。可搭配已有角色，或轮流导入表演，每次换稿前先导出。
