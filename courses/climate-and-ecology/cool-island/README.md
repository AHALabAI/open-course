# 城市凉岛：造一座会读天气的凉岛

为校园里真正停留的人，测出热、看见热、改变热。从一平方米出发，连接人的体验、遮阴材料、植物、天气与团队协作。

课程设计为六节，每节约 120 分钟。浏览器活动可独立运行；户外测量、原型施工与复测需要教师结合场地和年龄组织。

| 课次 | 入口 |
|---|---|
| 01 热从哪里来 | [观察人与空间](sessions/01-lesson/README.md) |
| 02 让热显形 | [测量与比较](sessions/02-lesson/README.md) |
| 03 四种凉意 | [机制与材料](sessions/03-lesson/README.md) |
| 04 AI 与天空搭档 | [概率与行动](sessions/04-lesson/README.md) |
| 05 一平方米建造 | [原型与使用者](sessions/05-lesson/README.md) |
| 06 凉岛开张 | [体验与复测](sessions/06-lesson/README.md) |

在 code/ 目录运行 `python serve.py --port 8826`，打开 http://127.0.0.1:8826/ 。无需 GPU、API Key 或额外 Python 库。具体见 [代码说明](code/README.md)。
