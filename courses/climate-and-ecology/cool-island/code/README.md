# 城市凉岛互动课程

为校园里真正停留的人设计一平方米的凉岛。这个网页包含六节课的活动安排、天气状态切换、马尔可夫概率演示和预警接力讨论。

## 启动

需要 Python 3.11+ 和现代浏览器，无需安装第三方库。在本目录运行：

```sh
python serve.py --port 8826
```

打开 http://127.0.0.1:8826/ 。按 Ctrl+C 关闭服务。主页面也能直接打开 web/index.html；来源链接需要联网。

## 修改

- web/index.html：课程文案与页面结构。
- web/app.js：情景切换、概率演示与交互。
- web/styles.css、tokens.css：布局与配色。

这份代码提供浏览器内的课程活动。页面中的天气概率、台风路径、评分榜单是教学示意，没有接入实时天气；不能用于实际预警或判断现场安全。页面提及的硬件建设与 Python 预测实验是延伸活动，不包含在这个网页包里。
