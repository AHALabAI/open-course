造一座会读天气的凉岛

学生为校园里真实停留的人，测出热、看见热、改变热。作品从一平方米出发，连接身体、材料、城市、厄尔尼诺、台风路径与校园预警行动。

领取委托

课程设计演示：尚未接入实时天气。天气概率、台风路径和榜单仅示范学习流程；现场项目仍需测量、施工与复测。

从皮肤，走到整片太平洋

学生在四种时间尺度之间移动。每次判断都写清地点、时段、指标、证据与下一次更新时间。

身体先告诉我们

手背感到椅面烫，脸侧感到风，影子告诉我们太阳来自哪里。学生用身体语言建立第一张热感地图。

证据：热感词、姿态、停留时间、现场照片

四个年龄段，共用一件真作品

年龄差异成为团队能力。每组共享一位使用者、一处地点、一套数据和一座凉岛。

K1–3体验观察员身体热感、影子绘图、人物采访、图标测试、30 秒讲述。
K4–6材料与场记员测量时间、材料数量、用水、照片、试验顺序和访客反馈。
K7–9数据与原型工程师传感节点、CSV、热力地图、结构连接、故障定位和游戏规则。
K10–12系统设计与研究员热平衡、多目标权衡、AI模型、气象数据、预算、安全和公开答辩。

L01热从哪里来身体漫游 · 真实委托＋

同一座校园，谁正在经历怎样的热？

  1. 0—15两把椅子的选择触摸、看影子、感受风，先写预测。
  2. 15—40校园热感漫游四人结伴，用贴纸记录晒、闷、烫、无风与久等。
  3. 40—60遇见真实使用者与保安、接送者、户外工作人员或同学完成短访谈。
  4. 60—90热问题词典把感受连接到地点、时刻、材料与行动。
  5. 90—120领取委托选择一位使用者和一个候选地点，完成 30 秒问题陈述。

L02让热显形工具侦探 · 测量契约＋

仪器给出不同答案时，怎样找到每个答案的意义？

  1. 0—15材料温度竞猜黑布、白布、金属、木材与草地排序。
  2. 15—40工具身份调查空气、表面、湿度、风速与身体热感各自留下什么证据。
  3. 40—65并排标定同类仪器一起读数，记录差值和时间。
  4. 65—100阳光／阴影配对统一高度、时间、距离、角度和材料。
  5. 100—120跨组复测另一组依据协议完成复现并提出修订。

测量契约

  • 时间、地点、天气、仪器、记录人齐全
  • 空气传感器拥有遮阳与通风
  • 表面测温记录材料、距离和角度
  • 每个结论至少三轮记录
L03四种凉意遮阳 · 反射 · 蒸发 · 通风＋

哪一种组合，能让目标使用者真正愿意停留？

  1. 0—15组合下注每组选择最有希望的降温组合并说明理由。
  2. 15—75四站轮转同尺寸模型完成遮阳、反射、蒸发和通风 A/B 测试。
  3. 75—95意外结果会诊挑选一条出乎预期的数据，改变一个变量再试。
  4. 95—110跨龄复现交换协议与材料，让另一组完成复测。
  5. 110—120机制入选选择进入凉岛的模块，并写出天气适用条件。

阶段档案

  • 阴影时间轴
  • 材料护照
  • 水—凉意曲线
  • 风路地图
  • 一条可迁移设计规则
L04AI 与天空搭档方案生成 · 台风路径 · 预警链＋

怎样让预测变成一条及时、清楚、适合校园的行动？

  1. 0—20天空简报现场观测、官方预报、模型更新、风险与行动。
  2. 20—40厄尔尼诺调查把海温异常、季节概率与本地数据放在两条时间轴。
  3. 40—60马尔可夫天气台从状态序列生成转移矩阵，预测下一时段概率并等待实况评分。
  4. 60—80追踪一只台风连接五个时刻，预测第六点，再与多模型路径比较。
  5. 80—100盘古路径实验读取公开样例、追踪低压中心、计算位置误差与提前量。
  6. 100—120妈祖预警接力观测员、模型员、预报员、风险员和校园行动员完成交接。

AI 工作契约

  • 模型输出带来源和更新时间
  • 模型分歧进入判断
  • 实况到来后计算误差
  • 校园行动写清责任人与触发条件
L05一平方米建造混龄施工 · 三状态压测＋

怎样让每一个构件都来自实验，也照顾真实使用动作？

  1. 0—20地面放样标出一平方米、通道、轮椅回转和停留姿态。
  2. 20—55骨架与配重完成连接、圆角、摇晃测试和成人结构审核。
  3. 55—80四机制安装每个模块贴上对应实验与使用者需求。
  4. 80—100传感与体验同步基线／原型节点，让不同身高和行动方式试用。
  5. 100—120三状态压测演练高温展开、强风收纳、雨后检查和责任交接。

放行证据

  • 实体原型 v1
  • 结构与电气检查
  • 同步传感数据
  • 可访问性走查
  • 三状态操作卡
L06凉岛开张公众试坐 · 热诊所 · 维护交接＋

作品怎样进入真实一天，并继续被使用与照顾？

  1. 0—20开放准备天气适用说明、分流、饮水、传感器与访客任务就位。
  2. 20—65热诊所试坐基线体验、凉岛任务、热感护照和同步数据。
  3. 65—8530 秒费曼解释用影子、布、水、风路或一条曲线讲清凉意。
  4. 85—105设计局答辩呈现预测、意外、证据、版本变化和下一步。
  5. 105—120维护与 Skill清洁、补水、存放、数据更新与个人方法进入交接。

四座实验站，四种可见机制

学生先下注，再改变一个变量。实验结果通过另一年龄组复现后进入共同凉岛。

让太阳绕开身体

改变高度、方向、孔隙和投影，画出阴影随时间移动的路径。

让材料少收一点热

比较颜色、表面和触感，同时观察眩光与周围人的体验。

让水带走热

记录水量、湿度、持续时间和触感，寻找天气适用条件。

让空气找到路

用丝带看见风，改变开口、导风板和模型密度。

本区概率与路径为教学示意，不是当前预报；季节资料须按发布日期阅读。
