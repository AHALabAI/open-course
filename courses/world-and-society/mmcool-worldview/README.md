# MMCOOL：我们生活在同一个世界

面对初中生的两天交流课，每天约 120 分钟。我们从一条消息、一个问题或一件作品出发，看看人们怎样理解世界、使用科技，也给自己的想法留一点空间。

课程围绕四条线：世界发生了什么；科学家和工程师怎样做；青少年有哪些行动；我们怎样在工坊里提出问题、做项目并回看证据。

两条持续的方向是与他人合作、关心他人，以及与真实世界建立物理联系。课程不要求学生当场选择人生方向，也不把好奇心或利他变成分数。
