# 第一天：看见世界的联系

建议 120 分钟，含休息。围绕来源、证据、决策和改变过的想法展开，活动可以按学习者的状态灵活调整。

| 入口 | 用法 |
|---|---|
| [演示课件](https://aha-lab.ai/course/mmcool-worldview/day1.html) | 方向键翻页，S 打开独立讲者窗，F 全屏 |
| [逐页讲稿](https://aha-lab.ai/course/mmcool-worldview/teacher-notes.html) | 备课、操作提示与讨论线索 |
| [工作纸](https://aha-lab.ai/course/mmcool-worldview/worksheet.html) | 留下一次判断、证据和修改 |
| [防灾游戏](https://aha-lab.ai/course/mmcool-worldview/game-guide.html) | 先作决定，再讨论结果及重新选择 |
| [材料出处](https://aha-lab.ai/course/mmcool-worldview/resources.html) | 回到原报道、研究和授权说明 |

不要把游戏分数直接当作学生能力或真实防灾效果。真实影像、新闻报道和机制示意需要分别说明，尚不能确定的原因就保留不确定性。
