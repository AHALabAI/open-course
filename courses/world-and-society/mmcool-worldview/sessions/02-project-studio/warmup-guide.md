# AI-or-human 暖场游戏

这是一个课堂互动游戏：先独立判断图片或视频，再说出依据，最后回到出处、制作记录和可复核证据。

打开 [网页使用说明](https://aha-lab.ai/course/mmcool-worldview/warmup/guide.html)，或访问 [公开课程资料](https://aha-lab.ai/course/mmcool-worldview/resources.html)。

代码与安装说明见 [AHALabAI/open-course](https://github.com/AHALabAI/open-course/tree/main/tools/warmup-ai-or-human)。
