# 项目工作室：从发现到第一版

这是 AHALab「我们生活在同一个世界」公开课程的项目工作室 session。学生从生活、学习和身边的人出发，提出一个愿意继续追问的问题，经过想象、规划、创造、验证、分享和提升，形成两周后的第一次项目分享。

## 课堂路径

提问 → 想象 → 规划 → 创造 → 验证分享 → 提升 → 再提问

课堂先用 AI-or-human 暖场工具帮助学生表达判断依据，再介绍项目循环，最后留下 1—3 个两周内值得调查的问题。学生可以独立或合作完成，不预设题目答案。
