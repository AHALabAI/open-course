# Draw a maze, care for animals

Two editable browser games for practising how to describe an idea, set rules, ask a friend to playtest, and improve a project. Choose either activity.

- [3D maze: run the game and edit a map](code/paper-maze/README.en.md)
- [Animal garden: run the game and change its behaviour](code/animal-garden/README.en.md)
- [60-minute paired activity](syllabus.en.md)
- [Teaching notes and classroom reflection (Simplified Chinese)](teaching-notes.md)

An adult helps with setup and any AI tools. Children choose what to make and try the result themselves. Paper design and playtesting do not require an AI account. The supplied game interfaces are in Simplified Chinese; these English instructions explain the controls.

The classroom example involved two children with adult support over nearly two hours. The 60-minute activity below is a reusable plan, not a claim that the full group lesson has been evaluated.
