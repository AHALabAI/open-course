# 60分钟活动安排

| 分钟 | 活动 |
|---|---|
| 0–4 | 介绍一件作品，问“你想做个什么？” |
| 4–10 | 两人轮流说想法，伙伴复述，可以画图或跳过公开发言。 |
| 10–17 | 讨论什么自己做、请朋友帮、请AI帮；AI可能出错，真实生活支持找可信任的人。 |
| 17–23 | 教师展示一次清楚的请求和生成结果，找一处需要核对的地方。 |
| 23–27 | 试玩迷宫或养成游戏，交换操作。 |
| 27–30 | 选一个改动：一段路线、一个动物动作或地图开放条件。 |
| 30–40 | 画图或修改程序；教师操作AI工具，学习者决定要求。 |
| 40–48 | 请伙伴试玩，先观察，不抢着解释。 |
| 48–54 | 根据一个具体问题改一处，再测试。 |
| 54–60 | 分享改了哪里、为什么改，保存作品。 |

迷宫方向：纸上画路，编辑器放起点、光晶、梯子和墙顶门。养成方向：画动作前、动作中、动作后三张图，再改喂食或玩球动作。
45分钟时减少演示和分享人数，保留双方表达、一次试玩和一次修改。
