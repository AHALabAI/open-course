# 小动物园

2D动物养成游戏：12只动物、四张地图，可起名字、喂食、玩球和寻找新动物。喂食有进食动作，玩球有追球、跳跃和音效。

## 运行

需要 Python 3.10+ 和现代浏览器，无需 npm、账号、密钥或在线素材。

```sh
python serve.py
```

打开 http://127.0.0.1:8768/ 。Windows可双击start.cmd。
局域网共享：`python serve.py --host 0.0.0.0`，其他设备打开主机的局域网地址和端口。
不要直接双击游戏HTML，浏览器模块需要HTTP服务。

## 玩法

给第一只小猫起名；点“找动物”，打开藏身处。找到的动物出现在下方，可选中继续照顾。
树林需要2只朋友和4次照顾；池塘需要5只朋友和12次照顾；雪地需要8只朋友和20次照顾。照顾包括喂食和玩球。
进度仅保存在当前浏览器。关闭页面不会扣减状态；没有生病、死亡或付费项目。
点击两次确认才会重新开始。

## 修改位置

- `animal-garden/garden.mjs`：MAPS配置地图条件，ANIMALS配置动物、颜色与食物，svg函数绘制外观。
- `animal-garden/garden.css`：喂食、玩球、打招呼动作和响应式布局。
- `animal-garden/lesson.html`：提问与设计活动卡。
