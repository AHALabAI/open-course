迷宫涂鸦

我来设计这一关

先选画布大小和迷宫配色，再点格子画墙与道路。起点与光晶放在路上，梯子放在靠墙的道路格，出口门放在墙格上。

×

宽、高各支持 5–43 格，包含外围墙。调整时保留左上方内容；缩小后超出边界的目标会重新安放，梯子靠墙、门在墙顶。扩大的区域可继续画路。

大地图可以在画布内左右、上下滚动，每格保持正方形。
S 起点 / L 梯子 / D 墙顶出口门 / ◆ 光晶 · 外圈保留围墙 · 最多 16 颗光晶

画好后检查一下

找出口的方法：在迷宫里找到 L 梯子 → 按 E 爬上墙顶 → 看见 D 出口门 → 沿墙顶走过去。请把门放在与梯子上方连通的墙格上。

墙面、地面、天空一起换色。画布即时预览，点“试玩我的迷宫”，看看画好的样子。

导出的 JSON 会保留地图尺寸、配色、梯子与门的位置，下次导入即可继续。试玩与返回时自动保留本标签页草稿。修改前先导出一份，留下你的第一版。

请朋友试玩时，先不告诉他路线。看看他在哪一格停下来。
